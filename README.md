# BioLab-Research-OOD
Проект по МИС
Описание на фирмата:
Провежда научни изследвания с офиси в София и Пловдив и изследователска лаборатория в
Троян. Лабораторията обработва секретни данни и е в напълно изолиран сегмент (airgap-
подобен). Само специфични машини от HQ могат да трансферират данни. NTP
синхронизацията е задължителна за всички сървъри.
